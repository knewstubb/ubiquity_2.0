# Journey Builder — Delivery Log

## 2026-07-28 — UX Feedback: Miro-style Canvas Interactions

**Source:** User feedback during walking skeleton review

**Request:** Make canvas interactions similar to Miro:

1. **Arrow cursor by default** — Not grab cursor
2. **Hover state on cards** — Visual feedback when hovering over nodes
3. **Finger cursor on (+) button** — Pointer cursor for insert buttons
4. **Click-and-drag does not select** — Dragging a node should move it without changing the inspector panel
5. **Click selects** — Single click on a node selects it and updates the settings panel
6. **Space bar for panning** — Pressing space changes cursor to pan hand, allows click-drag to pan canvas

**Status:** Implemented

**Priority:** UX polish — should be addressed before user testing
